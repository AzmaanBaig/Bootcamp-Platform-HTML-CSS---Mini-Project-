# ⚔️ CodeQuest Pro — The System

> *"The System has chosen you."*

A gamified coding platform inspired by **Solo Leveling** and modern platforms like HackerRank.
This project transforms coding practice into an immersive RPG-style experience with levels, XP, rankings, and interactive UI.

---

## 🚀 Features

* ⚡ **XP & Level System** — Gain experience and level up like a hunter
* 🏆 **Leaderboard System** — Compete with others in real-time rankings
* 💻 **Code Execution UI** — Simulated coding challenges with live visuals
* 🎯 **Achievement Badges** — Unlock milestones and progress ranks
* 📊 **Animated Stats Panel** — Dynamic HP, MP, and player stats
* 🌌 **Particle Background System** — Smooth animated UI effects
* 🎮 **Gamified UI/UX** — Inspired by Solo Leveling "System Interface"

---

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Advanced styling & animations
* **JavaScript (Vanilla)** — Logic, interactions, animations

---

## 📂 Project Structure

```
├── index.html     # Main structure
├── style.css      # Styling and animations
├── script.js      # Interactivity and logic
```

## ⚙️ How It Works

* The UI simulates a **game-like system interface**
* JavaScript powers:

  * Particle animations
  * Level counter
  * HP/MP dynamic bars
  * Scroll reveal effects
  * Interactive notification system
* CSS handles:

  * Dark theme
  * Glow effects
  * Smooth transitions
  * Responsive layout
